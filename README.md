# Sql-project-Retail-Inventory-Management-System-
This is a simple Retail Inventory Management System built using SQL. The project manages products, suppliers, customers, inventory, orders, and transactions for a small shop. With this database, you can add and update products, track stock, record customer sales and supplier purchases, and generate basic sales and inventory reports.​
What I Did in This Project
I created a new database called retailstore to store all my tables.

I made tables for suppliers, products, customers, inventory, orders, order details, and transactions.

I inserted sample data into each table, including example suppliers, products, customers, and starting inventory.

I ran SQL queries to:

View the current inventory,

Check which products are low in stock,

Track all transactions (purchases and sales),

Add new sales and purchase entries,

Summarize top-selling products by month,

List products for each customer order.

I updated and tested stock quantities with INSERT and UPDATE statements, then checked results with SELECT.

All my SQL code and data are in the attached script, and it shows how a small shop could manage inventory using just SQL.
